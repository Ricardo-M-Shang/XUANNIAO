# 玄鸟 · 山海舆图

依据《玄鸟设定与十四卷大纲校订稿》制作的纯前端交互地图。只收录山川、城池、海域和遗址，不展示人物、体质、修炼体系或剧情事件。

## 本地运行

需要 Node.js 20.19+ 或 22.12+；本环境已用 Node.js 24 验证。

```bash
cd /workspace/XUANNIAO/world-atlas
npm ci
npm run dev
```

开发服务默认监听 5173 端口。地图不需要后端、API 密钥或外部地图服务。字体随项目打包，安装依赖后不需要访问字体 CDN。

Windows 可直接双击仓库根目录的 `启动地图.cmd`。启动器会进入正确的项目目录，首次使用自动安装依赖；若解压包缺少锁文件则改用 `npm install`，随后在浏览器中打开地图。此启动器需要本机已安装 Node.js，云环境未执行 Windows 启动器。

```bash
npm run build     # 类型检查并输出静态网站到 dist/
npm run preview   # 本地检查生产构建
```

部署时将 `dist/` 作为站点根目录，使用任何支持 HTTPS 的静态托管服务即可。浏览器须支持 WebGL；若无法初始化，页面会显示提示。

## 地图内容

- **人界**：五洲、四海，22 处已知地理标记，含青牛村、灵墟洞天、昆仑、蓬莱、无尽渊海等。
- **灵界**：36 座可点选的洞天浮岛。纲要没有逐一命名，使用浏览编号，不创造正式地名。
- **仙界**：五城十二楼的天阙结构、月渡城、照川仙城、废弃天域、九天遗址等，共 8 处地标。
- 使用更细的地形网格、山脊扰动、贴地台基、颗粒地表、海岸礁岩、分层林冠与阔叶林、覆雪针叶林，支持 2.5D 与俯瞰视角，最高放大到 700%。
- 青牛村有房舍、田畴、水渠、木桥和转动水车；昆仑与灵墟有重檐院落、山门和曲折石阶；北洲雪关、蓬莱、断剑峰与古代遗址各有独立场景。皇朝标记附近的聚落只是区域景观示意，不是新增都城。
- 仙界中央有五座城台、宫殿院落和十二楼；照川按上城、中城、川下十三坊构建三个层次。灵界浮岛采用环列布局，拥有雪地、林泉、旧址和院落等视觉差异，均不补写正史命名或生态设定。
- 水面有细小波光、旋转海眼、岛岸瀑流与浮动帆船；北洲有细雪，云雾缓慢移动。可切换日间、黄昏、夜间，夜间窗格发暖光；支持暂停环境动态，并遵循浏览器减少动态效果偏好。
- 可直接点选三维建筑，也可从“地景选集”或地点详情“走近此地”进入局部细览。详情提供场景图、景观要素和原稿与视觉演绎的区别。小地图可点击导航并显示当前视野。
- 拖动、滚轮缩放、触屏单指平移与双指缩放、目录定位、跨界搜索、地点详情、图层开关、收藏及地点 URL。
- 收藏保存在当前浏览器的 `localStorage`。放大后显示更多地标；小屏幕概览会隐藏部分标签，避免拥挤，所有地点仍可通过目录或搜索访问。

快捷键：`/` 搜索，`+` / `-` 缩放，`0` 返回全图，`Esc` 关闭面板。

## 地理依据

地点数据集中在 [src/data.ts](src/data.ts)，每处地标都记录原稿出处、位置关系和示意说明。

建筑、田畴、道路、桥梁、船只、瀑流与岛屿生态均属于景观演绎；不据此新增港口名、都城名、行政边界或正式建筑平面图。日夜光照仅影响阅图效果，不代表剧情时间。

五洲四海、明确记载的地点归属与相对方位依据原稿。原稿没有精确地图，因此海岸线、河流、地形高度、植被、坐标、距离与配色均为视觉示意；龙津海、朝夕池及仙界各地的具体排列不视为正史。地图不提供虚构的实测距离、正式都城名或国界。

灵墟洞天保留为人界青崖山上的山门，不混入灵界三十六洞天。七政不是七个世界，因此不创建“七政七界”。九重天阙不拆成原稿没有记载的九块大陆。地理联系虚线仅表示原稿提及的联系，不代表确定道路。

页面的“制图说明”提供同样的说明；详情卡附有原稿章节出处。

## 验证

```bash
npm run test:e2e
```

此命令先构建，再用 Playwright 启动生产预览，验证三界浏览、地图点选、跨界搜索、收藏持久化、URL 恢复、视角缩放、图层、四海目录与移动端。

默认优先使用本机 `/usr/bin/chromium`。其他环境可先运行 `npx playwright install chromium`；也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定浏览器路径。浏览器测试在云环境使用软件 WebGL 渲染。

## 文件结构

```text
src/data.ts           地理数据、出处、地形轮廓与示意连接
src/geography.ts      山脊、台地、海岸与地表纹理生成
src/architecture.ts   批量生成房舍、飞檐、城墙、农田和各地场景
src/environment.ts    动态水面、海眼、云雾、细雪与光照类型
src/AtlasScene.ts     镜头、渲染、地标、建筑点选和图层
src/landscapes.ts     各地景观要素与视觉演绎说明
src/LandscapeArt.tsx  地景选集和详情卡的插图
src/MiniMap.tsx       小地图与视野导航
src/PlaceCard.tsx     地点详情与局部细览入口
src/main.tsx          React 目录、搜索、收藏与界面状态
src/styles.css        本地字体与基础响应式样式
src/landscape.css     景观版界面、光照主题与移动端适配
tests/atlas.spec.ts   浏览器功能验证
```
